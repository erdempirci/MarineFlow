# MarineFlow

Marine piping hydraulic calculation prototype.

## Prototype scope

- Single-pipe incompressible flow calculation
- Darcy-Weisbach major loss
- Reynolds number and flow regime
- Swamee-Jain friction-factor approximation for turbulent flow
- Minor losses from common marine fittings
- Static head and total required head
- Pressure-drop and pump-head summary
- Responsive, dependency-free frontend for Vercel

> Engineering prototype only. Results should be independently verified before design or procurement use.
